# OASIS UBL 2.1 schemas

XSD schemas of OASIS Universal Business Language 2.1 (Invoice and CreditNote plus the
common modules), as shipped with the KoSIT validator configuration for XRechnung
(`resources/ubl/2.1/xsd`, see `documentation/xRechnung`).

Original source: http://docs.oasis-open.org/ubl/os-UBL-2.1/

The unit tests validate the XRechnung UBL output of the library against these schemas
(see `tests/Envisia.InvoiceXml.Tests/XRechnungConformanceTests.cs`).
