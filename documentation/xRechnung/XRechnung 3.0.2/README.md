# XRechnung 3.0.2 test suite

`xrechnung-3.0.2-testsuite-2026-08-31.zip` contains the test documents of the XRechnung test suite,
release v2026-08-31 (https://github.com/itplr-kosit/xrechnung-testsuite/releases/tag/v2026-08-31),
licensed under the Apache License 2.0 by the Coordination Office for IT Standards (KoSIT).

The validator tests (`tests/Envisia.InvoiceXml.Tests/Validation/KositParityTests.cs`) validate these
documents and compare the reports with the reports of the KoSIT validator.
